# Hooks MB SYSTÈME — Swipe File

**MB SYSTÈME = Millionaire Behavior System**

Un hook est la première ligne d'un post. C'est le seul travail qu'elle doit faire : arrêter le scroll. Pas expliquer, pas vendre, pas enseigner. Arrêter.

Ce fichier contient 30 hooks en français et 30 hooks en anglais, organisés par angle psychologique. Utilise-les comme base — adapte le contexte à ton audience, à ton offre, à ta voix. Un bon hook est une porte ouverte. Le reste du post est ce qui se trouve derrière.

**Comment utiliser ce swipe file :**
- Ne copie pas mot pour mot. Adapte l'angle à ta réalité.
- Teste un hook = un post. Regarde ce qui retient l'attention, pas ce qui génère des likes.
- Le hook s'écrit en dernier. D'abord le message. Ensuite la première ligne.
